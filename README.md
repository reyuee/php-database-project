# php-database-project

Inlämning 1 i Webbserverprogrammering 1

En bloggsida med inloggning, formulär och databas. Man kan logga in
skriva ett inlägg och se det på sidan.

Databasen heter `practice` och har tabellerna `users` och `posts`.
Kör `database.sql` i phpMyAdmin för att skapa dem.

Skapa en `config.php` med `host`, `dbname`, `user` och `pass` innan du kör.
Lägg mappen i `htdocs` och öppna `localhost/php-database-project/`.
